# Who Held the Glass: social media kit

Launch assets for the interactive wine timeline on the Tannic Studio site
(`tannic-studio/page-who-held-the-glass.php`).

- `blog-post.md`: journal post introducing the piece
- `social-copy.md`: captions, pin copy, LinkedIn posts, Dribbble description, alt text and a rollout plan
- `images/`: every asset at its platform size

| File | Size | Use |
|---|---|---|
| `ig-carousel-01.png` … `ig-carousel-10.png` | 1080×1350 | Instagram carousel |
| `ig-sketchbook.png` | 1080×1350 | Instagram post spotlighting the illustrations |
| `ig-story.png` | 1080×1920 | Instagram story (add a link sticker) |
| `pinterest-01-chart.png`, `-02-moments`, `-03-south`, `-04-sketchbook` | 1000×1500 | Pinterest pins |
| `linkedin-link-card.png` | 1200×627 | LinkedIn link preview / share image |
| `linkedin-process.png` | 1200×1200 | LinkedIn "behind the build" post |
| `blog-header.png` | 1600×900 | Journal post header |
| `dribbble-01` … `dribbble-05`, `dribbble-07-illustrations` `.png` | 1600×1200 | Dribbble shots |
| `dribbble-06-motion.mp4` / `.gif` | 1600×1200 / 800×600 | Dribbble motion clip |

**Social look:** forest green leads, with deeper moss tones, lichen gold and pressed rosé
as accents (no terracotta), cream type, paper grain, a terroir-map contour texture,
and a loose wallpaper of Kate's vine. As small accents, the mushroom and morel are
inverted to pale line work so they read on green. On the sketchbook frames the three
drawings are featured in their original colours as taped specimen cards (the vine on
moss, the morel and mushroom on cream paper). Screenshots of the page keep the site's
own colours.

Charts in the images are drawn from `tannic-studio/data/who-held-the-glass.json`,
and UI shots are real renders of the page, so everything matches the live timeline.

This folder sits outside `tannic-studio/`, so it is never deployed to the site.
