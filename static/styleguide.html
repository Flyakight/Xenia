Style Guide

Every colour on this site comes from assets/css/tokens.css. Change a value there and the whole prototype re-tints, including the WordPress theme once this is ported back.

Brand palette

Fern
#568259 · var(--fern)

Botanical accent: eyebrows, amenity icons, the green band.

Beige
#EBEBD3 · var(--beige)

Page ground. Replaces the old cream.

Ink Black
#0D1F22 · var(--ink)

Body text, footer, dark sections. Replaces charcoal.

Terracotta Clay
#AD5D4E · var(--terracotta)

Primary accent: buttons, links, rules. Replaces gold.

Smoky Rose
#9B6A6C · var(--rose)

Secondary accent: meta text, citations. Replaces wine.

Semantic roles

Components never reference a raw hue. They reference a role, so a re-skin is a five-line edit.

RoleCurrentlyUsed by
--color-bgBeigebody, mobile menu
--color-surfaceBeige Lightcards, rail items
--color-surface-altWhitecontent sections, buttons
--color-textInk Blackbody copy, headings
--color-accentTerracotta Claybuttons, underlines, eyebrows
--color-accent-softSmoky Rosemeta text, citations
--color-natureFernamenity icons, green band, region labels
--color-inverse-bgInk Blackfooter, CTA sections

Type scale

Cormorant Garamond for headings, DM Sans for everything else. All headings are fluid via clamp().

H1 — Hero display

H2 — Section header

H3 — Subsection

H4 — Small heading

Body copy. Set at 1rem with a 1.8 line height and capped at 70ch so a paragraph never runs wider than the eye can track comfortably.
