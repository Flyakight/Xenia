The pressed register · Cloudinary

Baked server-side, delivered as a plain <img> — lazy loading, alt text and srcset all intact. Note the transformation order in every recipe: w_ comes before e_ordered_dither, so the dot pitch stays fixed relative to the layout instead of drifting with delivered width. Watch the weight readouts: halftones are high-frequency and often come back smaller as PNG than as AVIF.

C

Runtime vs baked

Same photograph, same intent. Left is pure CSS — a radial-gradient tile blended hard-light over the image at high contrast. It costs a network request of nothing, retunes live, and scales with the element. But it's a div with a background, so no alt text, no lazy loading, no srcset. Right is Cloudinary. This comparison is the whole question you asked.
